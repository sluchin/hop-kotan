# hop-kotan

忽布古丹醸造 (HOP KOTAN BREWING) のビールのデータをサイトから取得して、ソートやフィルタをして見る Android アプリ。毎日のタップリスト (忽布古丹のタップルーム BEER KOTAN) から、**その日に飲んだビールを記録**できます。

> 非公式の個人用のアプリです。ビールのデータの出典は忽布古丹醸造のサイト (https://hopkotan.com/) です。

## 仕組み

```
GitHub Actions (毎日) ──取得──> hopkotan.com
       │
       └─ data/taplist.json (今日のタップリスト) と data/beers.json (ORIGINALS と FREEDOMS) を更新
                     │
Android アプリ ◀── JSON をダウンロード (raw.githubusercontent.com)。端末で、ソートとフィルタ
       └─ 飲んだビールの記録は、端末に保存
```

アプリがサイトを直接取りにいくことはありません。サイトへのアクセスは 1 日に 1 回 (タップリスト) と、1 週間に 1 回 (ビール) だけです。

## データ

| ファイル | 内容 | 更新 |
|:---|:---|:---|
| [data/taplist.json](data/taplist.json) | 今日のタップリスト (更新日、量と価格、ビール名、スタイル) | 毎日 2 回 |
| [data/taplist/](data/taplist) | 日ごとのタップリストの履歴 (`YYYY-MM-DD.json`) と、その日付の目次 (`index.json`) | 毎日 2 回 |
| [data/beers.json](data/beers.json) | ORIGINALS と FREEDOMS のビール (名前、スタイル、発売月、ABV、IBU、元のページの URL) | 毎日 (新しいものがあれば) |

画像と説明文は保存しません (画像はサイトの URL を参照します)。

## 構成

| モジュール | 内容 |
|:---|:---|
| `core` | データの型、HTML の解析 (jsoup)、取得、JSON、飲んだ記録の集計 (Kotlin の JVM。カバレッジ 100%) |
| `scraper` | データを取得する、コマンドの入口 |
| `app` | Android アプリ (5 つのタブ: 今日、最近、ビール、記録、メニュー) |

## アプリ

| タブ | 内容 |
|:---|:---|
| 今日 | 今日のタップリスト (写真、ABV、IBU つき)。ビールをタップして、量 (M か L) を選ぶと、飲んだビールを記録します。今日の杯数、量、金額、純アルコール量も出ます |
| (全てのタブ) | **星 (5 つ) の評価**。今日と最近は長く押す、記録は押す、ビールは詳細の画面で、星を付けます。ビールごとの評価で、一覧に ★ を出します。端末の中だけに保存します (`ratings.json`) |
| 最近 | 最近 14 日分のタップリストを日ごとに見ます (見るだけ) |
| ビール | 全てのビール (写真つき。右に IBU と ABV の印)。画面には件数と「絞り込み」のボタンだけを出します。ボタンで開くポップアップで、名前とスタイルの検索、並べ方 (発売月、名前、ABV、IBU、スタイル、評価。昇順と降順)、スタイル、シリーズ、発売年、ABV と IBU の下限、評価 (星) の下限、今日のタップのみを選びます (選ぶと、すぐ一覧に反映します)。タップすると、詳細と「飲んだ」「サイトを開く」 |
| メニュー | お店の QR コードを読み込んで、メニューのページをアプリの中 (WebView) に表示します。QR コードは Google のコードスキャナで読みます (カメラの権限は要りません。Google Play 開発者サービスが必要です)。表示するのは https のページだけで、QR コードのホストの外へ移るときはブラウザで開きます。注文はメニューのページの中で行います (アプリは注文を代行しません)。下の帯にページの文字から見つけたビールを並べ (端末の中だけで探し、文字は保存しません)、タップして量を選ぶと、飲んだ記録に入れます。見つからないときは「探す」で探し直すか、「ほかを記録」で今日のタップから選びます。テーブルや注文の情報は保存せず、Cookie も消します |
| 記録 | 飲んだ記録を日ごとに表示します (杯数、量、金額、純アルコール量)。長く押すと、消せます |

起動のときに、データ (JSON) を GitHub から取得して、端末に保存します。写真は忽布古丹醸造のサイトの画像をそのとき取得して、端末に残します (アプリには含みません)。Material 3 の配色 (琥珀色。ライトとダーク) です。飲んだ記録は端末の中だけに保存します (どこにも送りません)。Android 13 以上が要ります。

**新しいビールの通知**: 3 時間ごとに (アプリを開いていなくても) 最新のタップリストを取得して、前の日のタップリストになかったビールがあれば、通知します (1 日に 1 回。ビールの比較は `core` の `NewTaps`。確認は `NewBeerWorker`、通知は `NewBeerNotifier`)。通知の権限を許可していないときは、通知しません。

## 使い方 (開発)

Docker があれば、動きます (Android Studio も、JDK も、要りません)。

```bash
export UID GID=$(id -g)
docker compose run --rm build          # APK (app/build/outputs/apk/plain/debug/app-plain-debug.apk)
docker compose run --rm test           # 単体テスト
docker compose run --rm scrape-taplist # data/taplist.json を更新
docker compose run --rm scrape-beers   # data/beers.json を更新 (初回は、時間がかかる)
```

そのほかのコマンドは [SETUP.md](SETUP.md) と [.claude/CLAUDE.md](.claude/CLAUDE.md) にあります。

## アイコン

オリジナルのアイコン (ビールのグラスとホップ) を使います。作者の端末のビルドだけは private のサブモジュール `private/` の、忽布古丹醸造のマークを使います (権利は忽布古丹醸造にあります。このリポジトリには含みません。配布もしません)。

## リリース

`v0.1.0` のようなタグを push すると、GitHub Actions の `release.yml` が APK (plain。オリジナルのアイコン) を作って、GitHub Releases の**ドラフト**に載せます (中身を確かめて、手で公開します)。APK はデバッグ鍵で署名したデバッグ版です。マークのアイコンの APK (marked) は権利が忽布古丹醸造にあるので、作りません。タグを打たずに試すときは Actions の Release を手動で実行します (成果物は Artifacts に保存されます)。
